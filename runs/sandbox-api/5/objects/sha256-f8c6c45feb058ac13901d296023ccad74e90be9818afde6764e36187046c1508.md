The checkout's use of these texts is the web team's part.

## Deviations

- The service code did not need to change for cross-origin access, apart from the one HTTP/0.9 fix above. The contract operation `cross_origin` records what the service already did, and the tests confirm it. This matches what the contract's Delivery note expected.
- The contract says the preflight does not check Access-Control-Request-Method or Access-Control-Request-Headers. It always answers with the same fixed list, instead of echoing the requested headers. A browser compares header names without regard to case, so this is not a problem for the checkout.
